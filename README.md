## Project Overview
We analyzed Pittsburgh neighborhoods to find the best places to live based on crime safety, service complaints, and access to trees.

## Datasets Used 

Our analysis uses publicly available data from the Western Pennsylvania Regional Data Center (WPRDC):

**2020 Census Population Data**	https://data.wprdc.org/dataset/2020-census-redistricting-data-extracts/resource/a8414ed5-c50f-417e-bb67-82b734660da6

**Monthly Criminal Activity Dashboard**	https://data.wprdc.org/dataset/monthly-criminal-activity-dashboard/resource/bd41992a-987a-4cca-8798-fbe1cd946b07

**City Trees Dataset**	https://data.wprdc.org/dataset/city-trees/resource/1515a93c-73e3-4425-9b35-1cd11b2196da

**311 Service Complaints**	https://data.wprdc.org/dataset/311-data/resource/76fda9d0-69be-4dd5-8108-0de7907fc5a4
